# Alumni screens

| Page | Implemented workflow |
| --- | --- |
| `/m/alumni` | Consent-filtered directory; office profile maintenance; owner-only publication and contact consent. |
| `/m/alumni/events` | Available events; office draft creation and open/close/cancel actions; own reservation for eligible alumni. |
| `/m/alumni/registrations` | Own reservations, or all reservations for administrators; cancel active reservation and release seat. |

Draft events remain office-only. Members without an alumni profile receive guidance instead of a reservation form. Consent controls carry current values and cannot target another person's profile. Every table, choice and action uses the existing plugin renderer and institution/role-gated host shell.
